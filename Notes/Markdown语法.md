# Markdown 语法示例

## 一、标题

```
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

## 二、换行

```
这是第一行··（末尾敲两个空格，再回车）
这是第二行（与上一行之间没有空行）

这是新段落（中间空一行，段落之间有空隙）
```

## 三、文字样式

- **加粗**：`**加粗**`
- *斜体*：`*斜体*`
- ~~删除线~~：`~~删除线~~`
- `行内代码`：用反引号包裹 `` `行内代码` ``

## 四、链接与图片

```markdown
链接：[百度](https://www.baidu.com)

图片：![百度logo](https://www.baidu.com/img/PCtm_d9c8750bed0b3c7d089fa7d55720d6cf.png)
```

## 五、列表

无序列表：

```markdown
- 项目一
- 项目二
  - 子项目（缩进两个空格）
```

有序列表：

```markdown
1. 第一步
2. 第二步
```

任务清单：

```markdown
- [ ] 待办事项
- [x] 已完成事项
```

## 六、代码块

````markdown
```python
def hello():
    print("hello world")
```
````

## 七、引用

```markdown
> 这是一段引用
> 可以多行
>> 引用里再嵌套引用
```

## 八、表格

```markdown
| 模块 | 说明 | 状态 |
| ---- | ---- | ---- |
| init | 初始化 | 待做 |
| train | 训练 | 进行中 |
```
